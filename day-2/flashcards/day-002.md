# Flashcards - Day 002

**Q1. What is the kernel?**
A: The privileged core of the OS that manages CPU, memory, devices and security.

**Q2. What is the difference between user space and kernel space?**
A: Kernel space has full hardware access; user space is restricted, so apps must ask the kernel for services.

**Q3. What is a system call?**
A: A controlled request from a program to the kernel (e.g. open a file, create a process).

**Q4. What is the difference between a program and a process?**
A: A program is a file on disk; a process is a running instance with its own memory and PID.

**Q5. What is the difference between a process and a thread?**
A: Threads live inside a process and share its memory; processes have separate memory.

**Q6. What does the scheduler do?**
A: Chooses which ready process gets the CPU next.

**Q7. What is PID 1 on Linux?**
A: init/systemd, the first process and ancestor of all others.

**Q8. Name the three kernel types with an example each.**
A: Monolithic (Linux), microkernel (Minix/QNX), hybrid (Windows NT, macOS XNU).

**Q9. Which kernel does macOS use?**
A: XNU, a hybrid kernel built on Unix (BSD) and Mach.

**Q10. Why is privilege escalation dangerous?**
A: It lets an attacker move from a limited account to admin/root or kernel level, gaining control of the whole system.
