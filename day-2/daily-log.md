## Day 002 - Operating systems: kernel, processes; Windows vs Linux vs macOS

### 3 things learned
1. The kernel is the privileged core, and user programs reach it only through system calls.
2. A process is a running program with its own memory and PID; threads share their process's memory.
3. Windows (NT, hybrid), Linux (monolithic) and macOS (XNU, hybrid) differ in kernel design, file systems and tooling.

- How a context switch saves and restores process state.
