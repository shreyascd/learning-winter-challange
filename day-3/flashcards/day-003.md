# Flashcards - Day 003

**Q1. What is a file system?**
A: The method an OS uses to organise data on storage: names, sizes, permissions and where each file's data sits.

**Q2. Name the default file system on Windows, Linux and macOS.**
A: NTFS (Windows), ext4 (common Linux default), APFS (macOS).

**Q3. What is journaling?**
A: Recording changes before writing them, so the file system can recover after a crash.

**Q4. What is the difference between an absolute and a relative path?**
A: Absolute starts from the root (`/` or `C:\`); relative starts from the current directory.

**Q5. What do `.` and `..` mean in a path?**
A: `.` is the current directory; `..` is the parent directory.

**Q6. Why are Linux paths case-sensitive?**
A: Linux treats `File.txt` and `file.txt` as different names; Windows and default macOS do not.

**Q7. Why is a file extension not proof of file type?**
A: It is just a label that anyone can change; real type is shown by the magic bytes.

**Q8. What is a double-extension attack?**
A: A file like `invoice.pdf.exe` that looks like a PDF but runs as an executable.

**Q9. What is a zip slip?**
A: An archive entry with `../` in its path that writes files outside the extraction folder.

**Q10. What is the difference between tar and tar.gz?**
A: tar only bundles files; tar.gz bundles and compresses them with gzip.
