# Flashcards - Day 006

**Q1. How many bits are in a byte, and what is its range?**
A: 8 bits; values 0 to 255.

**Q2. What does one hex digit represent?**
A: Exactly 4 bits (0-15).

**Q3. What is the ASCII value of `A`?**
A: 65 decimal, 0x41 hex, 01000001 binary.

**Q4. What is the ASCII value of the digit `0`?**
A: 48 decimal, 0x30 hex (not zero).

**Q5. What is the difference between `A` and `a` in binary?**
A: Only bit 5 (value 32) differs.

**Q6. What is a code point?**
A: The number Unicode assigns to a character, written U+XXXX (e.g. U+20AC for €).

**Q7. Why is UTF-8 backward compatible with ASCII?**
A: ASCII characters are stored as one byte with the same values.

**Q8. How many bytes does `€` take in UTF-8?**
A: Three: E2 82 AC.

**Q9. Is base64 encryption?**
A: No. It is encoding; anyone can decode it, so it hides nothing.

**Q10. What is a homoglyph attack?**
A: Using look-alike characters from another script (e.g. Cyrillic `а`) to fake a domain or name.
