## Day 005 - Command line tour: cmd and PowerShell basics, help flags
**Topic:** Command line tour - cmd and PowerShell basics, help flags

### 3 things learned
1. PowerShell uses verb-noun cmdlets and passes objects through pipelines, while cmd and bash pass text.
2. `/?` (cmd) and `Get-Help` (PowerShell) are the first place to check before guessing flags.
3. Encoded PowerShell (`-enc`) and download-and-run one-liners are common attacker patterns, so read commands before running them.
