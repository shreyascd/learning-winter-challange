# Flashcards - Day 005

**Q1. What is cmd?**
A: The classic Windows command shell; text in, text out, with commands like `dir`, `type`, `copy`.

**Q2. What is PowerShell?**
A: The modern Windows shell that uses verb-noun cmdlets and passes objects through pipelines.

**Q3. What does a verb-noun cmdlet look like?**
A: `Get-Process`, `Stop-Service`, `Get-ChildItem`.

**Q4. How do you get help for a cmd command?**
A: Add `/?` after it, for example `dir /?`.

**Q5. How do you get full help for a PowerShell cmdlet?**
A: `Get-Help <cmdlet> -Full` (or `-Examples` for usage examples).

**Q6. How do you find a command when you only know part of its name?**
A: `Get-Command *keyword*` in PowerShell.

**Q7. What does `Get-Member` show?**
A: The properties and methods of the objects in a pipeline.

**Q8. What is the difference between a PowerShell pipeline and a bash pipeline?**
A: PowerShell passes objects with properties; bash passes plain text.

**Q9. What is a red flag in a PowerShell command?**
A: `-enc` with a base64 string, or download-and-run patterns like `IEX` with `DownloadString`.

**Q10. Why check whether a shell is elevated?**
A: Admin rights let a command change system-wide settings; you should only use elevated shells when needed.
