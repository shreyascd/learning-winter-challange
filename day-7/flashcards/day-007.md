# Flashcards - Day 007 (Week 1 review)

**Q1. What are the main steps of the boot chain?**
A: Power on, firmware (BIOS/UEFI) with POST, boot device, bootloader, kernel, init, login.

**Q2. What is the difference between kernel space and user space?**
A: Kernel space has full hardware access; user space is restricted and uses system calls.

**Q3. What is the difference between a process and a thread?**
A: A process has its own memory and PID; threads share their process's memory.

**Q4. What is journaling?**
A: Recording changes before writing them so the file system can recover after a crash.

**Q5. Why are Linux paths case-sensitive?**
A: Linux treats `File.txt` and `file.txt` as different names; Windows and default macOS do not.

**Q6. What is the difference between a Type 1 and Type 2 hypervisor?**
A: Type 1 runs on bare metal; Type 2 runs as an app on a normal OS (e.g. VirtualBox).

**Q7. Why is a snapshot not a backup?**
A: It usually sits on the same disk, so a disk failure loses both.

**Q8. What does `/?` do in cmd, and what does `Get-Help` do in PowerShell?**
A: Both show built-in help for a command.

**Q9. How many bytes does a UTF-8 euro sign take?**
A: Three: E2 82 AC.

**Q10. Why is base64 not encryption?**
A: It is an encoding that anyone can decode, so it hides nothing.
