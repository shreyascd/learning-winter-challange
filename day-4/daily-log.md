## Day 004 - Virtualization lab: snapshots, host-only networking
**Topic:** Virtualization lab - snapshots, host-only networking

### 3 things learned
1. A snapshot freezes a VM's state and stores later changes separately, but it is not a backup.
2. Host-only networking keeps a VM off the internet and off the home or college network, which is what malware work needs.
3. Type 1 hypervisors run on bare metal; Type 2 (VirtualBox) run on top of a normal OS.
