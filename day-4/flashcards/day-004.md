# Flashcards - Day 004

**Q1. What is a virtual machine?**
A: A software-emulated computer with its own virtual CPU, RAM, disk and network card, running on a physical host.

**Q2. What is the difference between a Type 1 and Type 2 hypervisor?**
A: Type 1 runs directly on the hardware (ESXi, Xen); Type 2 runs as an app on a normal OS (VirtualBox, VMware Workstation).

**Q3. What hardware feature does virtualization need?**
A: CPU virtualization support: Intel VT-x or AMD-V, usually enabled in BIOS/UEFI.

**Q4. What does a snapshot capture?**
A: The VM's state (disk, and optionally memory) at a point in time, so you can roll back.

**Q5. Why is a snapshot not a backup?**
A: It usually sits on the same disk, so a disk failure loses both the VM and the snapshot.

**Q6. What is a differencing disk?**
A: A file that records changes made after a snapshot, while the original disk stays read-only.

**Q7. What does host-only networking allow?**
A: The VM talks to the host and other VMs on that network, but not the internet unless a second adapter is added.

**Q8. Why use host-only or internal networking for malware work?**
A: It keeps the infected VM isolated from the home or college network.

**Q9. What is the difference between NAT and bridged mode?**
A: NAT reaches the internet through the host without a visible IP; bridged gives the VM its own IP on the real network.

**Q10. What is a Windows evaluation VM?**
A: A fully working Windows from Microsoft's Evaluation Center with a time limit (typically 90 days), fine for labs.
